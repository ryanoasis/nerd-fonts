# Mona Sans Mono

Mona Sans Mono is the monospaced extension of Mona Sans, a strong and
versatile typeface designed by GitHub together with Degarism. It is suited to
code and interface typography and includes width and weight axes upstream.

This directory intentionally contains only the eight static, normal-width OTF
faces. Condensed and expanded widths are omitted to keep the generated Nerd
Fonts family focused and release size manageable.

For more information, see the upstream project:
https://github.com/github/mona-sans#mona-sans-mono-styles

Version: 2.0.27

## Licensing note

Names. A patched release therefore needs either a distinct family name or
written permission from the copyright holder to retain the upstream name.
