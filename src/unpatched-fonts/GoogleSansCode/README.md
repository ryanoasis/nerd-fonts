# Google Sans Code

**Google Sans Code** is designed to bring clarity, readability, and a bit of Google's distinctive brand character to code.

For more information have a look at the upstream website: https://github.com/googlefonts/googlesans-code

## Preprocessed Source Font

This source font has been preprocessed - it is not taken directly from upstream.
Google Sans Code is mainly a variable font (VF) and the static versions (that Nerd Fonts
are based on) are not part of the upstream's release. So we need to prepare them ourselves.

Download the two release fonts and call `generate_static.py`. The naming is not really
spot on, but the `font-patcher` will correct that anyhow.

At the moment the fonts are not hinted.

Version: 7.001
